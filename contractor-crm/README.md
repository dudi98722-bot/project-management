# ניהול קבלן וקבלני משנה 🏗️

מערכת שרת מלאה לניהול קבלן העובד עם קבלני משנה: פרויקטים לפי שלבים, תשלומי לקוחות
וקבלני משנה, הוצאות פרויקט ועסק, רווח צפוי מול בפועל, מודול בית נפרד, ודוחות.

בנוי על אותה תשתית של `crm-backend`: **Node + Express + PostgreSQL + JWT**.

---

## הרצה מקומית מהירה (מצב הדגמה, בלי שרת)

פותחים את `public/index.html` בדפדפן (או מגישים את התיקייה עם שרת סטטי), לוחצים
**"כניסה במצב הדגמה"** — והכל עובד עם נתונים לדוגמה בזיכרון, בלי מסד נתונים.
מצוין להתרשמות ולבדיקה לפני העלאה.

```bash
# הגשה סטטית מקומית
python -m http.server 3470 --directory public
# ואז לפתוח http://localhost:3470  →  "כניסה במצב הדגמה"
```

## התקנה על שרת (VPS) עם PostgreSQL

```bash
# 1) התקנת תלויות
cd contractor-crm
npm install

# 2) הגדרות סביבה
cp .env.example .env
#   ערוך את .env: DATABASE_URL, JWT_SECRET (מחרוזת אקראית ארוכה!), ADMIN_PASSWORD

# 3) יצירת הטבלאות + מנהל + נתוני דמו
npm run init-db

# 4) הרצה
npm start           # או: pm2 start server.js --name contractor-crm
```

מומלץ מאחורי nginx על תת-דומיין (כמו שאר האפליקציות), עם reverse proxy ל-`PORT`.

### משתמשים ראשוניים
- **מנהל**: `admin` / הסיסמא מ-`ADMIN_PASSWORD`
- משתמשי דמו לכל תפקיד (סיסמא `demo1234`): `secretary`, `owner`, `reporter`, `field`, `home`
  — למחוק/לשנות בפרודקשן דרך מסך "משתמשים".

---

## 6 התפקידים והרשאותיהם

| תפקיד | קוד | הרשאות |
|-------|-----|--------|
| מנהל | `admin` | הכל, כולל מחיקה מרובה וניהול משתמשים |
| מזכירה | `secretary` | הכל חוץ ממחיקה מרובה וניהול משתמשים |
| בעל עסק | `owner` | צפייה בכל הדוחות + הזנת נתונים, בלי מחיקה מרובה |
| מדווח (אמיתי) | `reporter` | דיווח תנועות עסק + צפייה בדוחות פרויקטים |
| עובד שטח | `field` | רק הזנת הוצאה לפרויקט + העלאת חשבונית |
| בית | `home` | רק מודול הבית |

ההרשאות מוגדרות ב-`middleware/auth.js` (אובייקט `ROLES`) — קל לשנות שם.

## Google Drive לחשבוניות (אופציונלי)

כל עוד לא מוגדר — חשבוניות נשמרות מקומית תחת `uploads/` ומוגשות מ-`/uploads/...`.
כדי לשמור בדרייב:

1. צור **חשבון שירות** ב-Google Cloud, הורד את קובץ ה-JSON.
2. שתף את תיקיית היעד בדרייב עם כתובת המייל של חשבון השירות (הרשאת עריכה).
3. ב-`.env`:
   ```
   DRIVE_FOLDER_ID=<מזהה התיקייה מה-URL>
   GOOGLE_SERVICE_ACCOUNT_FILE=/path/to/service-account.json
   ```
4. הפעל מחדש. מעכשיו חשבוניות עולות אוטומטית לתיקייה, והקישור נשמר בתנועה.

## מבנה

```
contractor-crm/
├─ server.js            # שרת Express, חיווט ה-routes
├─ db.js                # חיבור Postgres + audit log + מחיקה רכה
├─ drive.js             # העלאת חשבוניות (דרייב / מקומי)
├─ middleware/auth.js   # JWT + מטריצת הרשאות (6 תפקידים)
├─ db/schema.sql        # סכימת מסד הנתונים
├─ routes/              # auth, users, subcontractors, projects, stages,
│                       # transactions, home, reports, uploads, recycle
├─ scripts/init_db.js   # אתחול + זריעת נתוני דמו
└─ public/              # פרונט: index.html + store.js + app.js
```

## עקרונות
- **מחיקה רכה בלבד** — שום דבר לא נמחק פיזית. דגל `deleted` + סל מחזור עם שחזור, בכל הטבלאות.
- כל תנועה כספית משויכת: תשלום לקוח / תשלום קבלן משנה (פרויקט+שלב), הוצאת פרויקט (פרויקט), הוצאת עסק (חופשי).
- כל פעולת כתיבה נרשמת ב-`audit_log`.
