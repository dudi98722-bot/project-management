שלב 1 — הגדרה בגיליון (פעם אחת)

  1. פתח את הגיליון שלך בגוגל שיטס
  2. לחץ Extensions → Apps Script
  3. מחק את כל הקוד הקיים
  4. פתח את הקובץ google_apps_script.js מהמחשב שלך והדבק את כל תוכנו
  5. לחץ 💾 שמור
  6. לחץ Deploy → New deployment
  7. בחר Web app
    • Execute as: Me
    • Who has access: Anyone
  8. לחץ Deploy → אשר הרשאות → העתק את ה-URL
