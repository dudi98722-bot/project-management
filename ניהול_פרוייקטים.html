הגדרת Firebase

הגדרה זו נעשית פעם אחת בלבד

שלב 1 — צור פרוייקט Firebase

  1. גש ל־ console.firebase.google.com
  2. לחץ Add project → תן שם (למשל: proj-kablan)
  3. כבה Google Analytics → לחץ Create project
  4. לחץ Firestore Database → Create database → בחר Start in test mode
  5. לחץ Authentication → Get started → Email/Password → Enable
  6. לחץ Authentication → Users → Add user → הוסף כל עובד

שלב 2 — קבל את פרטי החיבור

  1. בפרוייקט Firebase לחץ ⚙️ Project settings
  2. מטה, תחת Your apps, לחץ </> (Web)
  3. תן שם לאפליקציה → לחץ Register app
  4. תראה קוד עם firebaseConfig — העתק את הערכים למטה
