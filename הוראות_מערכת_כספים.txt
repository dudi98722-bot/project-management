מערכת ניהול כספים — הוראות הקמה (3 שלבים, ~10 דקות)
======================================================

המערכת עצמה כבר מוכנה. כדי שהכל יעבוד בענן צריך 3 דברים חד-פעמיים:


שלב 1: יצירת ה-Backend בגוגל (Apps Script + Sheets)
-----------------------------------------------------
1. גלוש אל  https://script.google.com  (מחובר לחשבון dudi98722@gmail.com)
2. New project (פרויקט חדש)
3. מחק את הקוד שבעורך והדבק את כל התוכן של הקובץ:
      finance_sheets.gs   (נמצא בתיקיית "קלוד")
4. שמור (Ctrl+S), תן שם: "ניהול כספים בני"
5. Deploy (פריסה) > New deployment > בחר סוג: Web app
      Execute as:      Me
      Who has access:  Anyone   <-- חשוב! אחרת הטופס הציבורי לא יעבוד
6. לחץ Deploy, אשר הרשאות (Authorize -> בחר חשבון -> Advanced -> Go to... -> Allow)
7. העתק את הכתובת שמסתיימת ב-  /exec

   * הגיליון "ניהול כספים בני" ייווצר לבד ב-Google Drive בשימוש הראשון.

8. את הכתובת:
   א. הדבק במערכת: הגדרות > "חיבור לגוגל שיטס" > התחבר
      (זה מחבר את המחשב הזה; המערכת תעלה את הנתונים הקיימים לענן)
   ב. שלח גם לקלוד בצ'אט — כדי שיוטמע קבוע בקבצים, ואז כל מכשיר
      והטופס הציבורי יהיו מחוברים אוטומטית בלי שום הגדרה.


שלב 2: רשומת DNS (פעם אחת, דקה)
-----------------------------------------------------
ב-Namecheap (או איפה שמנוהל dudi-ananalytics.com):
   Advanced DNS > Add New Record:
      Type:  A Record
      Host:  kaspim          (או שם אחר שתבחר)
      Value: 64.176.175.180
      TTL:   Automatic


שלב 3: התקנה על השרת (פעם אחת, 2 דקות)
-----------------------------------------------------
היכנס לשרת (SSH דרך הקונסול של Vultr או PuTTY):
   ssh root@64.176.175.180

והרץ:
   curl -fsSL https://raw.githubusercontent.com/dudi98722-bot/project-management/main/deploy/deploy-finance.sh -o /tmp/df.sh && sudo bash /tmp/df.sh

(אם בחרת שם דומיין אחר מ-kaspim:
   sudo DOMAIN=השם-שלך.dudi-ananalytics.com bash /tmp/df.sh )
