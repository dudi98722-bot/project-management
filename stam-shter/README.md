# שטרנקוקר — ניהול רכישת ומכירת מוצרי סת"ם

מערכת ניהול לעסק סת"ם, בנויה על Node + PostgreSQL, עם ממשק עברי מלא.
האפיון המלא נמצא ב-[SPEC.md](SPEC.md).

**כתובת:** https://stam-shter.dudi-ananalytics.com

---

## מה יש במערכת

המערכת מורכבת משתי תת-מערכות **נפרדות בהזנה**, שנפגשות **רק בדוחות**:

### א. ס"ת
מעקב אחרי ספר שסופר כותב עבור רוכש — משני צדדיו:
- **צד סופר:** מחיר לעמוד, התקדמות עמודים, תשלומים, תיקונים, יתרה נוכחית ועתידית
- **צד רוכש:** מחיר כולל, חיוב לפי התקדמות, תשלומים (כולל מט"ח ופריטה), יתרה מיידית וכללית
- **רווח צפוי לכל ספר** — מחיר מכירה בניכוי עלות הסופר, פריטה, הוצאות קבועות, הוצאות לספר וצפי קלף

לשוניות תומכות: תשלום לסופר (תשלומים + יומן עמודים), תשלומי לקוחות, הוצאות לספר, הוצאות קלף, הוצאות עסק.

### ב. מוצרים
רכש ומכירה של מוצרים מוגמרים מהמלאי:
- רכישה מסופר יוצרת **חבילת מלאי**
- מכירה נגזרת מחבילה ספציפית, ולא ניתן למכור מעבר ליתרה
- רווח לכל מכירה, כולל ניכוי 3% אופציונלי

### דוחות
דשבורד · רווח כולל · רווח לפי ספר · יתרות סופרים · יתרות רוכשים · סיכום חודשי · מלאי ·
**כרטיס סופר** ו**כרטיס רוכש** — מאוחדים משתי המערכות.

## הרצה מקומית

בלי להתקין Postgres — הסקריפט מרים Postgres נייד:

```bash
npm install
npm run dev-local
```

המערכת תעלה על http://localhost:3620 · כניסה: `admin` / `admin1234`
המסד נשמר בתיקייה `.pgdata` (לא נכנס ל-git).

עם Postgres קיים:

```bash
cp .env.example .env     # ומלא DATABASE_URL ו-JWT_SECRET
npm run init-db
npm start
```

## פריסה לשרת

מהשרת:

```bash
sudo bash deploy-stam-shter.sh
```

הסקריפט (בתיקיית `deploy/` בריפו) מתקין Node ו-PostgreSQL אם חסרים, יוצר מסד ומשתמש,
מושך את הקוד, מגדיר systemd ו-nginx, ומוציא תעודת SSL. בסיום הוא מדפיס סיסמת אדמין אקראית.

עדכון גרסה אחרי `git push`:

```bash
sudo bash deploy-stam-shter.sh update
```

הסכימה מוחלת אוטומטית בכל עליית שרת, כך שעמודות חדשות נוצרות מעצמן.

## גיבוי לגוגל שיטס

הגיבוי אופציונלי — בלי הגדרה המערכת עובדת רגיל. הוא עובד דרך **Apps Script Web App**,
בלי חשבון שירות ובלי Google Cloud.

1. צור גיליון גוגל חדש
2. בגיליון: **תוספים ← Apps Script**, מחק את התוכן והדבק את [apps-script-backup.gs](apps-script-backup.gs)
3. **הגדרות הפרויקט (⚙) ← מאפייני סקריפט ← הוספת מאפיין:**
   `BACKUP_SECRET` = מחרוזת אקראית ארוכה שתמציא
   *(הסוד לא נמצא בקוד בכוונה, כדי שהקובץ יהיה בטוח לשמירה בריפו הציבורי)*
4. הרץ פעם אחת את הפונקציה `setupTabs` — מאשר הרשאות ויוצר את כל הלשוניות
5. **פריסה ← פריסה חדשה ← אפליקציית אינטרנט**, "הפעל בתור: אני", "גישה: כל אחד"
6. העתק את כתובת ה-`/exec` והוסף ל-`.env` שבשרת:
   ```
   BACKUP_WEBHOOK_URL=https://script.google.com/macros/s/AKfy.../exec
   BACKUP_SECRET=<אותו ערך בדיוק כמו המאפיין שבסקריפט>
   ```
7. `sudo systemctl restart stam-shter`

בדיקה שהכל תקין: פתח את כתובת ה-`/exec` בדפדפן — אמורה לחזור
`{"ok":true,"service":"stam-shter backup","configured":true,...}`.
אם `configured` הוא `false`, המאפיין `BACKUP_SECRET` לא הוגדר.

מרגע זה כל פעולה נרשמת בלשונית **"פעולות"**, וכל טבלה משוקפת בלשונית משלה
(שורה מתעדכנת לפי מזהה, לא נוספת מחדש).

הפעולות נצברות ונשלחות באצווה כל ~1.5 שניות, כדי לא לחרוג ממכסת Apps Script
ולא לעכב את המשתמש. כשל בשליחה לא מפיל פעולה במערכת — יש שלושה ניסיונות ואז ויתור עם רישום ללוג.

> ה-Web App פתוח לכל מי שמכיר את הכתובת, ולכן **הסוד המשותף הוא מה שמגן על הגיליון**.
> אל תפרסם אותו, ואם דלף — החלף אותו בשני המקומות ופרוס מחדש.

## עקרונות מימוש

- **מחיקה רכה בלבד.** שום דבר לא נמחק פיזית. כל רשומה מסומנת `deleted` וניתנת לשחזור
  מלשונית **סל מחזור**. מחיקת ספר מעבירה גם את כל יומניו לסל, ושחזור מחזיר רק את
  אלו שנמחקו באותה פעולה.
- **מקור אמת אחד לחישובים.** כל נוסחאות הס"ת יושבות ב-[calc.js](calc.js) ומשמשות
  גם את הלשונית וגם את הדוחות, כדי שלא ייווצרו שתי אמיתות.
- **"תיקונים" הוא דגל, לא שם.** סוג הוצאה מסומן בעמודת `is_correction`, כך שאפשר
  לשנות את שם הסוג בלי לשבור את החישוב, ואפשר לסמן יותר מסוג אחד.
- **יומן פעולות.** כל הוספה/עריכה/מחיקה נרשמת ב-`audit_log` עם משתמש וזמן.

### הערת תכן
מספר העמודים, יחידות הקלף וההוצאה הקבועה נלקחים **מהמוצר בזמן אמת**, לפי האפיון.
משמעות הדבר: שינוי מוצר בהגדרות משפיע גם על ספרים קיימים מאותו סוג. אם בעתיד יידרש
שכל ספר ישמור את הערכים שלו בנפרד — זו תוספת קטנה של שדות על טבלת `scrolls`.
