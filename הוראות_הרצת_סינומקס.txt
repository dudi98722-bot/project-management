  הוראות להרצת סקריפט סינומקס
══════════════════════════════════════════════════

שלב 1 — הורדת credentials.json (פעם אחת בלבד)
─────────────────────────────────────────────────
1. כנס ל: https://console.cloud.google.com
2. לחץ על "Select a project" (למעלה) → "New Project"
   → שם: "Sino Docs" → Create

3. בתפריט שמאל: "APIs & Services" → "Enable APIs and Services"
   → חפש "Google Drive API" → Enable
   → חזור → חפש "Google Sheets API" → Enable

4. בתפריט שמאל: "APIs & Services" → "Credentials"
   → "+ Create Credentials" → "OAuth client ID"
   → Application type: Desktop app
   → Name: Sino → Create
   → לחץ על "Download JSON" (כפתור ⬇)

5. שנה את שם הקובץ ל: credentials.json
   ושמור אותו בתיקייה:
   C:\Users\בונים ומוגנים\OneDrive\שולחן העבודה\קלוד\

6. בפעם הראשונה תצטרך לאשר ב-OAuth consent screen:
   → "APIs & Services" → "OAuth consent screen"
   → External → Create
   → App name: Sino Docs, שמור את האימייל שלך → Save
   → "+ Add users" → הוסף את האימייל שלך → Save

══════════════════════════════════════════════════

שלב 2 — הרצת הסקריפט
─────────────────────────────────────────────────
פתח PowerShell (או Command Prompt) בתיקייה קלוד והרץ:

  python upload_sino_to_drive.py

בפעם הראשונה:
• ייפתח חלון דפדפן — אשר את ההרשאות
• לאחר האישור הסקריפט ימשיך אוטומטית
• הקישורים יישמרו בקובץ sino_links.txt

══════════════════════════════════════════════════

מה הסקריפט עושה:
• יוצר תיקייה "סינומקס - מסמכים 2026" בדרייב
• מעלה את כל הקבצים עם תת-תיקיות לפי קטגוריה:
  - חשבוניות מס
  - קבלות
  - פרופורמות
  - מס הקצאה
  - כרטסות
  - תמונות וצ'קים
  - קבצי אקסל
• יוצר Google Sheets עם לשונית לכל קטגוריה
  + לשונית סיכום עם קישורים לכל תת-תיקייה
