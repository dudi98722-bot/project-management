🔗 חיבור ל-Google Sheets

פעם ראשונה בלבד — בצע את השלבים הבאים כדי לחבר את האפליקציה ל-Google Sheets

  1. פתח Google Sheet חדש ב-sheets.google.com
  2. לחץ על Extensions → Apps Script
  3. מחק את הקוד הקיים, הדבק את תוכן הקובץ crm-script.gs
  4. לחץ Deploy → New deployment
  5. בחר Type: Web app | Execute as: Me | Access: Anyone
  6. לחץ Deploy, אשר הרשאות, העתק את ה-Web app URL
  7. הדבק את ה-URL בשדה למטה
