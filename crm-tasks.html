⚙️ הגדרת Firebase

פעם ראשונה בלבד — הכנס את פרטי Firebase כדי שהנתונים יסתנכרנו בין כל המכשירים

  1. היכנס ל-console.firebase.google.com
  2. צור פרויקט חדש (חינמי)
  3. לך ל-Realtime Database → צור מסד נתונים (בחר "test mode")
  4. לך להגדרות הפרויקט (⚙️) → הוסף אפליקציית Web
  5. העתק את הפרטים למטה
