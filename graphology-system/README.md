# מערכת אבחון גרפולוגי — ישראל הפטקה

כלי עבודה מקצועי לניתוח כתב יד והפקת דוחות גרפולוגיים, מבוסס על מאגר הידע
שחולץ מקובץ העבודה הקיים (`קובץ קיים.xlsx`) ועל מסמך האפיון.

## איך מפעילים
פותחים את `index.html` בדפדפן (כרום/אדג'). אין צורך בהתקנה או אינטרנט.
חשוב שהקובץ `kb.js` יישאר באותה תיקייה לצד `index.html` — שם נמצא מאגר הידע.

## מה יש במערכת
- **לוח בקרה** — סיכום תיקים, סטטוסים ועומסים.
- **תיקים** — כרטיס לקוח/מועמד: פרטים, מטרת אבחון, מזמין, מחיר, סטטוס, מצב פיזי, הערות.
  כפתור "הנחיות כתיבה ללקוח" מפיק טקסט מוכן להעתקה.
- **ניתוח כתב היד (Workbench)**:
  - מאגר של **512 סימנים גרפולוגיים** מקובצים לפי סדר הבדיקה (ארגון, מרווחים, תנועה,
    צורה, חתימה ועוד) — בחירה בלחיצה ושליפת המשמעות אוטומטית.
  - סימון כל סימן כ**בולט** או כ**דורש בירור (ספק)**.
  - **מנוע הצלבות**: סופר אילו טיפוסי אודם ואילו תכונות חוזרים על עצמם בסימנים שנבחרו.
  - בחירת טיפוס **יונג** (עמדה + פונקציה) ו**אודם** דומיננטי, עם הצגת המשמעות מהמאגר.
- **דוח** — מפיק דוח בפורמט הקיים: סימנים בולטים, פסקת ניתוח (עם טיוטה אוטומטית),
  מקצועות, המלצות, טבלת סימנים מלאה, יונג/אודם, נקודות לבירור, פסקת "שריר ההצלחה"
  והסתייגות מקצועית. ייצוא ל-**Word** או **הדפסה/PDF**.
- **מאגר הידע** — עיון וחיפוש בכל הסימנים + מילון 80 המונחים.
- **הגדרות** — שם הגרפולוג, נוסח ההסתייגות, פסקת הסיום, וגיבוי/שחזור נתונים.

## נתונים וגיבוי
כל הנתונים נשמרים מקומית בדפדפן (localStorage). מומלץ ללחוץ "גיבוי" מדי פעם
ולשמור את קובץ ה-JSON. "שחזור" טוען אותו בחזרה (גם במחשב אחר).

## הרחבות עתידיות (לפי האפיון)
התאמה תעסוקתית לפי צירים, השוואת מועמדים, מודל הולנד (RIASEC), העלאת תמונת כתב יד
לצד הטופס, ומחולל טקסט חכם. השלד בנוי כך שאפשר להוסיף אותם בהדרגה.
